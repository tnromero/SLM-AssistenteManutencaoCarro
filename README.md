# Repositorio

## Objetivos de estudo

Este projeto explora:

- uso de SLM local;
- classificação com modelos pequenos;
- estratégias híbridas Rule Based + SLM;
- validação de respostas geradas;
- fallback determinístico;
- avaliação de qualidade;
- avaliação de latência;
- avaliação de custo;
- generalização;
- integração de SLM em uma arquitetura Clean Architecture.

`uv sync`
